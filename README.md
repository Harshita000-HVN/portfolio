## 📌 Overview

This repository contains the personal portfolio website of **Harshita Vasudev Naik**, a Software Engineer focused on full-stack application development.

The portfolio has been designed as a modern digital resume and professional showcase. It presents technical skills, internships, academic background, projects, and contact information through an interactive and responsive user experience.

The application is built using **React.js and Vite**, with a custom CSS design system and **Framer Motion** animations.

### Core Focus

* Full-stack web development
* Java backend development
* Spring Boot REST API development
* React.js frontend development
* MySQL and relational database design
* Authentication and authorization concepts
* Responsive UI engineering
* Clean and maintainable application architecture
* Professional developer branding

# 💡 Design Philosophy

The portfolio follows several engineering and design principles.

### 1. Simplicity

The interface avoids unnecessary complexity while maintaining a premium visual experience.

### 2. Responsiveness

Every major interface component is designed to adapt to different screen sizes.

### 3. Reusability

Portfolio information is maintained using structured JavaScript data rather than repeatedly hard-coding individual UI elements.

### 4. Performance

Vite provides a fast development environment and optimized production build pipeline.

### 5. Accessibility

The interface uses semantic HTML elements, accessible labels, buttons, and meaningful interaction patterns where applicable.

### 6. Maintainability

The project keeps the application logic, content data, and styling organized so future updates can be made without redesigning the entire application.

# 📥 Installation

### Step 1 — Clone the Repository

```bash
git clone https://github.com/Harshita000-HVN/portfolio.git
```

### Step 2 — Navigate to the Project

```bash
cd portfolio
```

### Step 3 — Install Dependencies

```bash
npm install
```

### Step 4 — Start Development Server

```bash
npm run dev
```

The terminal will provide a local development URL, normally:

```text
http://localhost:5173
```

Open that address in your browser.
